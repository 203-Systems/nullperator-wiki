# Make your first loop

This short walkthrough continues from [Quick start](./quick-start), which ends
on Project after saving:

1. <KeyCombo keys={['Shift', 'Down']} /> Return to Song.
2. <KeyCombo keys={['Shift', 'Right']} /> Open Chain 00.
3. <KeyCombo keys={['Shift', 'Right']} /> Open Phrase 00.

You should now see `C3 I00` at row `00`, and Instrument 00 should be set to
OPAL.

## 1. Place four notes

Keep the cursor in the `NOTE` column.

1. Tap <Keycap>Down</Keycap> four times to reach row `04`, then tap <Keycap>Enter</Keycap>.
2. Tap <Keycap>Down</Keycap> four more times to reach row `08`, then tap <Keycap>Enter</Keycap> again.
3. Tap <Keycap>Down</Keycap> four more times to reach row `0C`, then tap <Keycap>Enter</Keycap> once more. `0C`
   is hexadecimal row index 12.

Each new row reuses the most recent note and instrument, so all four rows should
show `C3 I00`:

```text
00  C3  I00
04  C3  I00
08  C3  I00
0C  C3  I00
```

Rows between them stay empty. That spacing creates an even four-beat pulse.

<InterfaceShot src="img/screens/phrase-loop.png" alt="Phrase view with notes on rows 00, 04, 08, and 0C">
  The four notes are evenly spaced across the 16-row Phrase.
</InterfaceShot>

## 2. Hear the loop

Tap <Keycap>Play</Keycap>. The four notes should repeat in order, and a filled triangle
appears in the top bar while playback is running. Tap <Keycap>Play</Keycap> again to stop.

If only the first row makes sound, check that rows `04`, `08`, and `0C` each
show both a note and `I00`. If nothing plays, return to Instrument 00 and check
that its Type is `OPAL`.

## 3. Shape the melody

Stop playback, then try changing two notes:

- On row `04`, hold <Keycap>Enter</Keycap> and tap <Keycap>Right</Keycap>. The note moves to the next note
  in the project scale. With the default Chromatic scale, `C3` becomes `C#3`.
  Release <Keycap>Enter</Keycap> when it sounds right.
- On row `08`, hold <Keycap>Enter</Keycap> and tap <Keycap>Up</Keycap>. The note moves up one octave. Release
  <Keycap>Enter</Keycap> to finish the edit.

Tap <Keycap>Play</Keycap> again. You should now hear the same rhythm with a changing pitch.

## 4. Keep it

Return to Project with <KeyCombo keys={['Shift', 'Left']} /> twice, then <KeyCombo keys={['Shift', 'Up']} />. Keep the
cursor on Name, move the bottom-bar choice to **Save**, and press <Keycap>Enter</Keycap>. If the
project is still `UNTITLED`, NullPerator asks for a name first and then
continues the save. Wait for the saving mark to disappear before closing the
app, powering off, or removing storage.
