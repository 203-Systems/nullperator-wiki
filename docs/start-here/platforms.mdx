# Use NullPerator anywhere

NullPerator hardware, Web, and iOS use the same tracker screens, instruments,
project format, and action names. Learn <Keycap>Shift</Keycap>, <Keycap>Option</Keycap>, <Keycap>Enter</Keycap>, and
<Keycap>Play</Keycap> once, then move between devices without relearning the workflow.

<PlatformMatrix />

The [controls at a glance](../controls/buttons) show the mappings for every
platform. The rest of the manual uses the shared names <Keycap>Shift</Keycap>, <Keycap>Option</Keycap>,
<Keycap>Enter</Keycap>, and <Keycap>Play</Keycap>, rather than splitting each task into three versions.

## Keep a portable copy

Keep a second copy outside the device you compose on. Copy projects from the
NullPerator hardware SD card, export a ZIP from the Web Files panel, or copy
the NullPerator folder from iOS Files. Local app or browser storage should not
be the only copy of important work.

See [Files and compatibility](../reference/files-and-compatibility) when you
want to move projects or samples by hand.
