# Table

Tables are reusable 16-step effect sequences. A table can be referenced by a Phrase `TBL` command or assigned to an instrument, letting effects evolve independently of the Phrase grid.

NullPerator has **32 tables**, IDs `00`–`1F`. Each row contains three command/value pairs that advance in parallel.

## Phrase and Instrument contexts

The top bar prefixes the table number with its entry context:

- `P00` is the **Phrase Table** context. Enter it from Phrase; if the current Phrase row contains a `TBL` command, its value selects the table.
- `I00` is the **Instrument Table** context. Enter it from Instrument; an assigned instrument table selects the number.

Both contexts edit the same 32-table bank. The prefix records where Up should return and which track/instrument reference should be followed; it is not a second copy of table data.

Hold <Keycap>Shift</Keycap> and press <Keycap>Right</Keycap> from a Phrase Table to inspect the Instrument Table context. Hold <Keycap>Shift</Keycap> and press <Keycap>Left</Keycap> from an Instrument Table to return to Phrase Table context.

## Columns

| Pair | Contents |
| --- | --- |
| `FX1` + value | First effect lane and four-digit hexadecimal value |
| `FX2` + value | Second effect lane and four-digit hexadecimal value |
| `FX3` + value | Third effect lane and four-digit hexadecimal value |

An empty command is `---`; an empty value is `0000`. The bottom bar normally shows live notes, and replaces them with help when the cursor's FX lane contains a command. During playback, separate marks can show the ordinary table and instrument-automation positions in each FX lane.

## Edit commands and values

Directions move through the fixed 16 × 6 grid. Tap <Keycap>Enter</Keycap> to recall the last command or value for the current cell.

Hold <Keycap>Enter</Keycap> to edit:

| Cell | <Keycap>Left</Keycap> / <Keycap>Right</Keycap> | <Keycap>Down</Keycap> / <Keycap>Up</Keycap> |
| --- | --- | --- |
| FX command | Previous / next command | Coarse alphabetic command jump |
| Four-digit value | Move the active digit | Decrease / increase that hex digit |

The highlighted digit corresponds to a step of `1000`, `0100`, `0010`, or `0001`. Each command applies its own valid range, so the value may clamp rather than wrap.

Hold <Keycap>Enter</Keycap> and <Keycap>Option</Keycap> together to cut a cell. Cutting an FX command clears its paired value as well.

## Select the table and track context

Hold <Keycap>Option</Keycap> without <Keycap>Enter</Keycap> or <Keycap>Shift</Keycap>:

- <Keycap>Left</Keycap> / <Keycap>Right</Keycap> selects the previous or next track, then resolves the relevant Phrase or Instrument table reference on that track.
- <Keycap>Up</Keycap> / <Keycap>Down</Keycap> changes the table ID by `10` hexadecimal, wrapping between the `0x` and `1x` banks while preserving the low digit.

The top prefix and table number receive focus while <Keycap>Option</Keycap> is held; the grid cursor does not move.

## Selection and clipboard

Begin Selection Mode with <KeyCombo keys={['Shift', 'Option']} sequence />, then release <Keycap>Shift</Keycap> and extend the rectangle with the directions.

| Input while selected | Result |
| --- | --- |
| <KeyCombo keys={['Shift', 'Option']} sequence /> | Expand across all six columns; repeat to select all 16 rows |
| <Keycap>Option</Keycap> | Copy and exit Selection Mode |
| <KeyCombo keys={['Enter', 'Option']} /> | Cut and exit Selection Mode |
| <Keycap>Enter</Keycap> + direction | Adjust every selected cell |
| <Keycap>Play</Keycap> | Play the current Phrase context |

Paste with <KeyCombo keys={['Shift', 'Enter']} /> after Selection Mode closes. Table clipboard data remains type-aligned. It can move between `P` and `I` Table contexts, and compatible FX command/value pairs can also be transferred between Table and Phrase. NullPerator rejects a command-to-value or NOTE-to-FX reinterpretation.

On the value of a `TBL` command, the immediate clone gesture—
<KeyCombo keys={['Shift', 'Option']} sequence />, keep <Keycap>Shift</Keycap>
held, release <Keycap>Option</Keycap>, then press <Keycap>Enter</Keycap>—
duplicates the referenced table into a free slot and updates that value.

## Playback and track state

- <Keycap>Play</Keycap> starts or stops the current Phrase context on the selected track. The Table cursor row does not become a Phrase start row.
- <KeyCombo keys={['Shift', 'Play']} /> starts or stops the whole Song from the stored Song cursor.
- <KeyCombo keys={['Option', 'Play']} /> toggles solo for the selected track.
- <KeyCombo keys={['Option', 'Shift']} sequence /> toggles mute for the selected track.
- <KeyCombo keys={['Shift', 'Option', 'Play']} /> clears all track mutes and solo state.

## Page navigation

Hold <Keycap>Shift</Keycap> and use:

- <Keycap>Up</Keycap> → Phrase from a `P` table, or Instrument from an `I` table
- <Keycap>Right</Keycap> → Instrument Table from Phrase Table
- <Keycap>Left</Keycap> → Phrase Table from Instrument Table
