# Song and Live

Song is the top level of a NullPerator project. Its grid is an arrangement of **chains**: each non-empty cell contains the ID of the chain that a track should play at that Song row.

The same screen has two transport behaviors:

- **SONG** plays the arrangement linearly.
- **LIVE** cues chains without leaving the grid, so rows can be recombined during a performance.

Hold <Keycap>Option</Keycap> and press either <Keycap>Left</Keycap> or <Keycap>Right</Keycap> to switch between the two. The selector wraps because it contains exactly two choices.

<InterfaceShot src="img/screens/song.png" alt="NullPerator Song view with eight track columns and contextual bottom bar">
  Eight tracks share one 128-row arrangement; sixteen rows are visible at once.
</InterfaceShot>

## Fields

| Area | Meaning |
| --- | --- |
| `SONG` / `LIVE` | Current sequencer mode |
| `T1`–`T8` | Eight independent tracks |
| `00`–`7F` | 128 Song rows; 16 rows are visible at once |
| `00`–`FE` | Chain IDs |
| `--` | No chain on this track and row |
| Bottom bar | The most recent live note on each track; editing help and notices temporarily take priority |
| Playback marks | Active and queued positions for each track |

An empty cell is not a rest inside a chain. It means that the Song row does not start a chain on that track.

## Try this

1. Put the cursor on a filled chain cell and tap <Keycap>Play</Keycap>. Song begins at the
   selected row; tap <Keycap>Play</Keycap> again to stop.
2. Hold <Keycap>Option</Keycap> and tap <Keycap>Left</Keycap> or <Keycap>Right</Keycap>. The title changes from `SONG`
   to `LIVE`.
3. In LIVE, move to another filled cell and tap <Keycap>Play</Keycap>. That chain is queued for
   the selected track.
4. Switch back to SONG with <KeyCombo keys={['Option', 'Left']} /> or
   <KeyCombo keys={['Option', 'Right']} />.

The [first-loop walkthrough](../start-here/first-loop) shows how to create the
Phrase and Chain used by a Song cell.

## Navigation and chain entry

Use the directions to move through the grid. Moving past the top or bottom of the 16-row window scrolls through the full 128-row Song.

Hold <Keycap>Enter</Keycap> to edit the current chain ID:

| Direction | Change |
| --- | ---: |
| <Keycap>Left</Keycap> / <Keycap>Right</Keycap> | `-1` / `+1` |
| <Keycap>Down</Keycap> / <Keycap>Up</Keycap> | `-10` / `+10` in hexadecimal (`-16` / `+16`) |

Release <Keycap>Enter</Keycap> to commit the edit. Holding a direction repeats the change.

Tap <Keycap>Enter</Keycap> to use the last-chain entry behavior:

- On an empty cell, the last selected chain ID is inserted.
- On a filled cell, that ID becomes the last selected chain.
- A second consecutive <Keycap>Enter</Keycap> allocates a new chain and places its ID in the cell.

Hold <Keycap>Enter</Keycap> and <Keycap>Option</Keycap> together to cut the current cell. The press order does not matter.

Hold <Keycap>Option</Keycap> and press <Keycap>Up</Keycap> or <Keycap>Down</Keycap> to jump to the previous or next populated section on the current track. Sections are blocks of chain cells separated by empty rows; an entirely empty or gapless track does not jump.

## Selection and clipboard

Selection is deliberately order-sensitive so that it can share the same four product keys as mute:

1. Hold <Keycap>Shift</Keycap>.
2. Press <Keycap>Option</Keycap> to begin a selection at the cursor.
3. Release <Keycap>Shift</Keycap>, then use the directions to extend the selection.

The Song clipboard can hold at most the visible **8 × 16** grid. A selection cannot grow beyond 16 rows.

While a selection is active:

| Input | Result |
| --- | --- |
| Directions | Extend or shrink the selected rectangle |
| <KeyCombo keys={['Shift', 'Option']} sequence /> | First select the full row width; repeat to select the full visible grid |
| <Keycap>Option</Keycap> | Copy, then leave Selection Mode |
| <KeyCombo keys={['Enter', 'Option']} /> | Cut, then leave Selection Mode |
| <Keycap>Enter</Keycap> + direction | Adjust every selected cell using the same fine/coarse steps as a single cell |
| <Keycap>Play</Keycap> | Run the current transport action; in LIVE, cue the selected track span |

After copying or cutting, hold <Keycap>Shift</Keycap> and press <Keycap>Enter</Keycap> to paste at the cursor. A clipboard from Chain, Phrase, Table, or Groove is intentionally incompatible with Song and will not be pasted.

### Clone a chain

To duplicate the chain referenced by one Song cell, begin selection with
<KeyCombo keys={['Shift', 'Option']} sequence />, keep <Keycap>Shift</Keycap>
held, release <Keycap>Option</Keycap>, and press <Keycap>Enter</Keycap> as the
next action. NullPerator allocates a new chain, copies all 16 phrase and
transpose rows, and replaces the cell with the new ID.

## Playback in Song mode

- <Keycap>Play</Keycap> starts the whole arrangement at the selected Song row; press it again to stop.
- <KeyCombo keys={['Shift', 'Play']} /> uses the same Song transport while in SONG mode.
- <KeyCombo keys={['Option', 'Play']} /> toggles solo for the current track. With a horizontal Song selection, it solos that selected track span.
- Hold <Keycap>Option</Keycap>, then press <Keycap>Shift</Keycap> to toggle mute for the current track or selected track span.
- <KeyCombo keys={['Shift', 'Option', 'Play']} /> clears every mute and solo state.

<Admonition type="note" title="Modifier order">
<KeyCombo keys={['Shift', 'Option']} sequence /> begins a selection. <KeyCombo keys={['Option', 'Shift']} sequence /> toggles mute. This distinction is intentional.
</Admonition>

## Playback in Live mode

Live mode uses the selected Song row as a cue source.

- <Keycap>Play</Keycap> cues the chain on the current track. If transport is stopped, Live starts with that track. During playback, the cue normally takes effect at the next chain boundary.
- Press <Keycap>Play</Keycap> again on the same queued item to tighten the cue to the next phrase boundary.
- <KeyCombo keys={['Enter', 'Play']} /> cues the current track immediately, at the next tick boundary.
- Hold <Keycap>Left</Keycap>, then press <Keycap>Play</Keycap> to cue the current row across all eight tracks.
- During playback, <KeyCombo keys={['Shift', 'Play']} /> queues the current track to stop. Repeating the chord tightens the stop from a chain boundary to a phrase boundary.

Only playable cells are queued. Empty Song cells are ignored rather than shown as active playback.
