# Chain

A chain turns a set of phrases into a longer musical block. Song cells refer to chains; each chain then plays up to 16 phrase rows in order.

NullPerator provides chain IDs `00`–`FE`. Each chain contains exactly 16 rows, `00`–`0F`.

<InterfaceShot src="img/screens/chain.png" alt="NullPerator Chain view with phrase and transpose columns">
  PH references a Phrase; TR offsets it in signed decimal semitones.
</InterfaceShot>

## Fields

| Column | Meaning | Empty display |
| --- | --- | --- |
| `PH` | Phrase ID `00`–`FE` | `--` |
| `TR` | Signed semitone transpose, `-99` to `+99` | `---` when `PH` is empty |

Transpose is shown in signed decimal. `+12` raises the phrase by one octave and `-12` lowers it by one octave.

## Try this

1. Put the cursor on a filled `PH` cell and tap <Keycap>Play</Keycap> to hear the Chain from
   that row. Tap <Keycap>Play</Keycap> again to stop.
2. Move to its `TR` cell, hold <Keycap>Enter</Keycap>, and tap <Keycap>Right</Keycap> once. The transpose
   becomes `+01`.
3. Tap <Keycap>Play</Keycap> again. The Phrase now plays one semitone higher.
4. Hold <Keycap>Enter</Keycap> and tap <Keycap>Left</Keycap> to return the transpose to `+00`.

## Navigation and editing

Directions move the cursor through the fixed 16 × 2 grid. Hold <Keycap>Enter</Keycap> to edit without moving the cursor:

| Column | <Keycap>Left</Keycap> / <Keycap>Right</Keycap> | <Keycap>Down</Keycap> / <Keycap>Up</Keycap> |
| --- | ---: | ---: |
| `PH` | `-1` / `+1` phrase | `-10` / `+10` in hexadecimal (`-16` / `+16`) |
| `TR` | `-1` / `+1` semitone | `-12` / `+12` semitones |

The transpose value saturates at `-99` and `+99`; it does not wrap through an unsigned hexadecimal value.

Tap <Keycap>Enter</Keycap> on `PH` to recall the last phrase ID. A second
consecutive <Keycap>Enter</Keycap> allocates a new phrase and writes its ID into
the row. On `TR`, <Keycap>Enter</Keycap> recalls the last non-zero transpose.

Hold <Keycap>Enter</Keycap> and <Keycap>Option</Keycap> together to cut the current cell. Cutting `PH` leaves its transpose data stored but hidden until a phrase is assigned again; cutting `TR` resets it to `+00`.

## Change context with Option

Hold <Keycap>Option</Keycap> without <Keycap>Enter</Keycap> or <Keycap>Shift</Keycap>:

- <Keycap>Left</Keycap> / <Keycap>Right</Keycap> selects the previous or next track and resolves the chain at the current Song row.
- <Keycap>Up</Keycap> / <Keycap>Down</Keycap> loads the chain from the adjacent Song row on the selected track. If that Song cell is empty or the Song edge has been reached, the Chain view stays where it is.

The top chain ID and the selected track in the bottom bar move with this context. The cell cursor remains on the same Chain row and column.

## Selection, copy, and clone

Begin Selection Mode with <KeyCombo keys={['Shift', 'Option']} sequence />, then release <Keycap>Shift</Keycap> and extend the rectangle with the directions.

| Input while selected | Result |
| --- | --- |
| <KeyCombo keys={['Shift', 'Option']} sequence /> | Expand to both columns; repeat to expand to all 16 rows |
| <Keycap>Option</Keycap> | Copy the selection and exit Selection Mode |
| <KeyCombo keys={['Enter', 'Option']} /> | Cut the selection and exit Selection Mode |
| <Keycap>Enter</Keycap> + direction | Adjust every selected cell |
| <Keycap>Play</Keycap> | Play the current Chain context |

Paste a copied Chain selection with <KeyCombo keys={['Shift', 'Enter']} /> after Selection Mode has closed. Clipboard data stays column-aligned, so phrase IDs and transposes cannot cross into one another.

To clone one referenced phrase, place the cursor in `PH`, begin selection with
<KeyCombo keys={['Shift', 'Option']} sequence />, keep <Keycap>Shift</Keycap>
held, release <Keycap>Option</Keycap>, and press <Keycap>Enter</Keycap>
immediately. NullPerator allocates a new phrase, copies all of its steps, and
replaces the `PH` cell with the clone's ID. The clone gesture is not available
in `TR`.

## Playback and track state

- <Keycap>Play</Keycap> starts or stops this chain from the highlighted Chain row, on the selected track.
- <KeyCombo keys={['Shift', 'Play']} /> starts or stops the whole Song from the stored Song cursor.
- <KeyCombo keys={['Option', 'Play']} /> toggles solo for the selected track.
- <KeyCombo keys={['Option', 'Shift']} sequence /> toggles mute for the selected track.
- <KeyCombo keys={['Shift', 'Option', 'Play']} /> clears all track mutes and solo state.

The playback mark follows every track currently using the displayed chain. The bottom bar shows live notes for `T1`–`T8` unless selection, clipboard, or editing help temporarily replaces it.
