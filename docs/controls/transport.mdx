# Playback, mute, and solo

<Keycap>Play</Keycap> is contextual. A plain press starts from the current Song,
Chain, Phrase, Table, Groove, or selection context; tapping it while active
stops playback. On sequencer pages with local playback, <KeyCombo keys={['Shift', 'Play']} /> requests full Song
transport. In Live, <KeyCombo keys={['Shift', 'Play']} /> starts the focused track or selected span when
transport is stopped, or queues that same target to stop while transport is
running.

The top bar shows a filled triangle and elapsed time while playback is
running. Playback cursors only mark populated material: an empty track is not
painted as though it had a chain.

## Song and Live

In Song, hold <Keycap>Option</Keycap> and press either horizontal direction to switch the
two-item bottom selector between **SONG** and **LIVE**. The selector wraps; no
extra arrow prompt is required.

In Live, <KeyCombo keys={['Enter', 'Play']} sequence /> starts the focused item immediately.
<KeyCombo keys={['Left', 'Play']} sequence />
cues the current Song row across all eight tracks.

<KeyCombo keys={['Option', 'Up']} /> or <KeyCombo keys={['Option', 'Down']} /> jumps between populated Song sections.

## Sample preview and recording

In the Sample Browser, Sample Editor, and Slices, tap <Keycap>Play</Keycap> to
start a local preview and tap again to stop. Releasing the button keeps the
preview running. Long WAV previews stop at the end; short single-cycle WAV
previews in the browser and editor loop until stopped.

Stop sequencer playback before previewing samples. In the Sample Browser,
<KeyCombo keys={['Shift', 'Play']} /> imports the selected library WAV.
[Record](../sampling/recording) uses <Keycap>Enter</Keycap> to start and stop
capture, then opens the Sample Editor for preview and saving.

Holding <Keycap>Enter</Keycap> on a Phrase note still auditions that note only
while held; this is separate from the sample preview control.

## Mute and solo

The order matters because <KeyCombo keys={['Shift', 'Option']} sequence /> starts Selection. <KeyCombo keys={['Option', 'Shift']} sequence />
toggles mute for the current track, or for the horizontal span of an active
Song selection. <KeyCombo keys={['Option', 'Play']} sequence /> toggles solo.
To clear every mute and solo, use
<KeyCombo keys={['Option', 'Shift', 'Play']} sequence />. <Keycap>Play</Keycap>
must be last; this order avoids leaving the grid in Selection Mode.

Master in Mixer has no mute or solo action.
