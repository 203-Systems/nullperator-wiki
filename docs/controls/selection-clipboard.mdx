# Selection and clipboard

Song, Chain, Phrase, Table, and Groove support bounded selections. There is no
separate paste mode: the clipboard remains available after copying, and
<KeyCombo keys={['Shift', 'Enter']} /> pastes once at the current cursor whenever the page is compatible.

## Begin and resize

1. Press and hold <Keycap>Shift</Keycap>.
2. Press <Keycap>Option</Keycap>.
3. Release the modifiers, then use directions to extend from the anchor. Song,
   Chain, Phrase, and Table use all four directions; Groove uses <Keycap>Up</Keycap> and <Keycap>Down</Keycap>.

The bottom bar reads **Selection Mode** and explains the next action. Repeat
Use <KeyCombo keys={['Shift', 'Option']} sequence /> to expand the selection preset: first across the page's row or
columns, then across the visible page. Groove has only one column, so its first
repeat selects all 16 visible steps.

<Admonition type="warning" title="Order matters">

<KeyCombo keys={['Option', 'Shift']} sequence /> is **Mute**, not Selection. Start with <Keycap>Shift</Keycap>.

</Admonition>

## Clipboard actions

Copy and Cut exit Selection Mode. Paste writes at the cursor and leaves the
clipboard reusable. Adjusting a range applies the field's fine or coarse step
to every compatible cell; Groove does not batch-adjust this way. In Song, <Keycap>Play</Keycap>
uses the selected horizontal track span.

Copy and Paste each show a two-second bottom-bar notice including the
selection dimensions. If the clipboard's page/column shape cannot be pasted at
the target, NullPerator leaves the data unchanged and shows an incompatibility
message.

## Clone a referenced resource

Clone is a deliberate ordered gesture used on cells that reference reusable
resources:

1. Use <KeyCombo keys={['Shift', 'Option']} sequence /> on the reference cell.
2. Keep holding <Keycap>Shift</Keycap>, release <Keycap>Option</Keycap>, then press <Keycap>Enter</Keycap>.

NullPerator clones the referenced resource into the next free slot and replaces
the cell with that new number. Any unrelated input cancels the pending clone.

## Groove exception: interpolate

Inside a Groove selection, <KeyCombo keys={['Shift', 'Enter']} /> interpolates values between the two
endpoints instead of pasting. A successful operation shows **Interpolated** and
the number of affected steps. To paste Groove data, leave Selection Mode first,
move to the destination, then use <KeyCombo keys={['Shift', 'Enter']} />.
