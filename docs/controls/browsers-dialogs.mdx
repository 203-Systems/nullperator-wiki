# Browsers and dialogs

NullPerator uses full-screen browsers for projects, samples, instruments,
and themes. Choosing a project loads the song; choosing a sample or instrument
loads or imports it into the current project.

## Browser conventions

- <Keycap>Up</Keycap> / <Keycap>Down</Keycap> moves the row cursor.
- <Keycap>Left</Keycap> / <Keycap>Right</Keycap> moves through actions in the bottom bar.
- <Keycap>Enter</Keycap> activates the selected row or action.
- `..` enters the parent directory. It does not close the browser.
- <KeyCombo keys={['Shift', 'Left']} /> returns to the page that opened the browser.

Sample and Project browsers add their own preview, import, and delete actions.
Deleting something always asks for confirmation first.

## Rename keyboard

Rename opens a dedicated screen rather than floating above the previous page.
The title sits at the top, the input field below it, and the keyboard fills the
lower area.

- Directions move between keys.
- <Keycap>Enter</Keycap> activates the focused key.
- <Keycap>Shift</Keycap> toggles letter case; the letters on the keyboard update immediately.
- The icon keys provide case, space, and backspace.
- The bottom actions are **Cancel / Random / Save**.

Save is dimmed and disabled while the name is empty. If the name already exists
or saving fails, the screen stays open and tells you what happened.

## Confirmations and feedback

In a confirmation, move to the action you want and press <Keycap>Enter</Keycap>.
**No / Cancel** is on the left and **Yes / Replace** on the right. Two-state
selectors likewise place **Off / No / False** before **On / Yes / True**.

Hold <Keycap>Shift</Keycap> on a child page, including Sample Edit, Slices,
Record, or a browser, to show **Back** in the top-right navigation area. Use
<KeyCombo keys={['Shift', 'Left']} /> to return. Sample Edit asks before
abandoning an unsaved take, an edited range, or applied operations. Starting a
new project also asks before replacing a project with unsaved changes.

Brief results such as **Copied**, **Pasted**, or **Locked** appear in the bottom
bar. Errors that need your attention open a message in the middle of the
screen. Rendering shows its progress and can be cancelled.
