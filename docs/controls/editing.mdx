# Change notes and values

NullPerator separates **moving** from **changing**. In tracker grids, directions
move the cursor and <Keycap>Enter</Keycap> plus a direction changes the active
value. In settings lists, horizontal directions make the everyday adjustment
directly, while <Keycap>Enter</Keycap> plus a vertical direction provides the
faster step.

## Tracker grids

- Press <Keycap>Enter</Keycap> on an empty resource cell to initialize it.
- Use <KeyCombo keys={['Enter', 'Left']} /> or <KeyCombo keys={['Enter', 'Right']} /> for the fine step.
- Use <KeyCombo keys={['Enter', 'Up']} /> or <KeyCombo keys={['Enter', 'Down']} /> for the coarse step.
- Keep a direction held to repeat.

The coarse amount follows the field. For example, a Chain phrase changes by 16
and its transpose changes by an octave (12 semitones). On a Phrase note the
bottom bar names the two axes **Note** and **Oct** instead of showing numeric
step sizes.

Pressing <Keycap>Enter</Keycap> on an empty Song, Chain, Phrase, or Table cell fills it with a
useful starting value. A new Phrase note also selects Instrument 00, but you
still need to choose a sound for that instrument.

## Four-digit effect values

Phrase and Table effect parameters are four hexadecimal digits. Hold <Keycap>Enter</Keycap> and
press <Keycap>Left</Keycap> / <Keycap>Right</Keycap> to move the digit focus.
<Keycap>Up</Keycap> / <Keycap>Down</Keycap> edits the focused digit. The
command mnemonic remains highlighted while either its mnemonic or its value is
active, and the bottom bar continues to show command help.

## Project, Device, and Instrument lists

For an editable list value:

- <Keycap>Left</Keycap> / <Keycap>Right</Keycap> changes the normal step without a modifier.
- <KeyCombo keys={['Enter', 'Up']} /> or <KeyCombo keys={['Enter', 'Down']} /> changes the coarse step where that value defines one.
- Enumerations wrap when their field is designed as a circular selector.

Scale and Root can still be changed while <Keycap>Enter</Keycap> is held, but they remain
enumerations rather than numeric coarse-step fields. Disabled or unavailable
items do not silently become editable.

When a note can be previewed, keep <Keycap>Enter</Keycap> held to hear it and release <Keycap>Enter</Keycap> to
stop. If normal playback is running, stop it before previewing a single note.
